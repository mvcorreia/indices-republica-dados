# Driver incluído

Esta pasta contém os componentes oficiais do Xerial SQLite JDBC 3.54.1.0:

- `sqlite-jdbc-3.54.1.0-without-natives.jar`: classes Java do driver;
- `sqlite-jdbc-3.54.1.0-natives-all.jar`: bibliotecas nativas para os sistemas suportados.

Os scripts `executar.bat` e `executar.sh` já incluem `lib/*` no classpath.
Não é necessário instalar um servidor de banco de dados.

Projeto e licença: https://github.com/xerial/sqlite-jdbc
